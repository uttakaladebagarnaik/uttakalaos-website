# UTTAKALA OS

Your Personal Life OS — Official Production Distribution Repository.

This repository hosts official verified releases of UTTAKALA OS for Windows Desktop and Android.

## Platforms
- **Windows Desktop:** 64-bit NSIS Setup Installer and Portable Executable
- **Android:** Direct universal signed APK (`com.uttakala.lifeos`)
- **Apple iOS:** Native Xcode project scaffold (TestFlight Beta coming soon)
