UNCOMPROMISING HONESTY

What We Guarantee — And What We Don't

Many productivity tools mislead users with marketing buzzwords like "bank-grade military encryption." At UTTAKALA OS, we state the exact factual parameters of our implementation.

Verified Architecture Facts

  • Local-Only Secret Diary Secret Diary entries are stored strictly in local application storage (Room/SQLite). They are physically excluded from Supabase cloud sync and from Google Drive backups. If you uninstall the app without manual export, they are erased with the sandbox.
  • User Google Account Isolation Backups utilize Google Drive's restricted AppData folder (`drive.appdata` scope). Other applications and file explorers cannot see this folder, keeping backup files isolated to UTTAKALA OS.
  • Supabase PostgreSQL Row Level Security Cloud routines, habit records, and academic schedules synced via Supabase are protected by PostgreSQL RLS policies tied to your authenticated Supabase user UID.
  • Zero Third-Party Ad Trackers There are no Facebook Pixels, Google AdSense tags, adjust SDKs, or commercial telemetry beacons bundled inside the app or the website.

Explicit Technical Disclosures

  • Google Drive Backups Are NOT Encrypted Backup payloads uploaded to your Google Drive AppData folder are formatted as raw, unencrypted JSON. They inherit Google's transit (TLS) and at-rest cloud security, but are NOT end-to-end encrypted with an independent cipher.
  • Secret Diary Encryption Status Secret Diary entries are protected by an in-app biometric/passcode gate and stored in private local database files. We do not claim cryptographic zero-knowledge or hardware HSM encryption unless explicitly audited [OWNER REVIEW REQUIRED].
  • No Enterprise SOC-2 / ISO Inventions We do not falsely claim SOC-2 Type II, ISO 27001, HIPAA, or FedRAMP compliance certifications. We rely on verified infrastructure provided by Supabase and Google Cloud.
  • User Backup Responsibility Because local data is sovereign, users must periodically trigger manual Google Drive backups or offline JSON exports to avoid data loss during device replacement.
