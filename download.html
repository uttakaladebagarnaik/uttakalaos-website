Installation Guidance

Important steps for independent desktop and mobile installations.

Windows SmartScreen Notice

Because UTTAKALA OS is an independent sovereign release without costly commercial Microsoft CA certificates, Windows Defender SmartScreen may display: "Windows protected your PC".

  1. Click More info on the SmartScreen dialog.
  2. Confirm the publisher is independent and click Run anyway.
  3. The NSIS installer will install UTTAKALA OS to your user profile directory without requiring administrator root tampering.

Android Sideloading & Battery Settings

Installing directly outside Google Play requires allowing installation from your file manager or browser:

  1. Tap UTTAKALA-OS-v1.0.apk in your Downloads folder.
  2. When prompted, tap Settings and enable Allow from this source.
  3. Crucial for Vivo, Xiaomi, Oppo: In App Info > Battery, select Unrestricted / High Background Power so Funtouch OS / MIUI does not freeze your 25-minute background Focus Timer.
